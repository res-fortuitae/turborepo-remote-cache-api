# Security policy

Please do not report vulnerabilities in public issues or pull requests.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/res-fortuitae/turborepo-remote-cache-api/security/advisories/new).
Include the affected version or commit, reproduction steps, and the impact you
observed.

Fixes target the latest commit on `main`. The design and trust boundaries are
described in [docs/threat-model.md](docs/threat-model.md).
